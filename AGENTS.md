# Instrucciones permanentes para Codex

- Trabaja exclusivamente en Windows nativo.
- Utiliza PowerShell para automatización y scripts.
- No utilices WSL ni Docker.
- Ejecuta las pruebas pertinentes antes de considerar completada cualquier modificación.
- Mantén compatibilidad con ejecución en CPU aunque CUDA no esté disponible.
- No añadas al repositorio modelos, audios, vídeos, entornos virtuales, resultados de transcripción ni otros archivos pesados.
